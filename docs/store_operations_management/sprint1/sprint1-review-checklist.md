# Sprint 1 Review Checklist

レビュー日: __________
担当者: __________
Role: 代表・副社長 / 営業部長 / エリアマネージャー / 店長

## 起動・データ境界

- [ ] Chrome Consoleにエラーがない
- [ ] Runtime=`ready`で5秒以内にMockデータが表示される
- [ ] Previewとサンプルデータの注意書きがある
- [ ] 実績値ではないことを理解できる
- [ ] 日本語の画面名になっている

## Dashboard

- [ ] 全店の状況を確認できる
- [ ] 総売上（税込）の対象期間が分かる
- [ ] 利益状態が「確定」「集計中」「準備中」で分かる
- [ ] 要対応店舗数がすぐ分かる
- [ ] 優先して確認することが最大3件である
- [ ] 業績を動かした要因が4分類である

## 店舗一覧・詳細

- [ ] 店舗状態フィルターと件数が正しい
- [ ] 5種類の並び替えを操作できる
- [ ] 店舗行またはカードから詳細へ移動できる
- [ ] 戻ったときに一覧条件が保持される
- [ ] 店舗詳細が4タブだけである
- [ ] 正式20店舗名に誤りがない

## Role・レスポンシブ

- [ ] 代表または副社長で全20店舗
- [ ] 営業部長で直営13店舗
- [ ] エリアマネージャーで担当5店舗
- [ ] 店長で自店舗詳細へ直接着地
- [ ] スマートフォンで店舗カード表示
- [ ] ページ全体の横スクロールがない
- [ ] タップだけで主要操作ができる
