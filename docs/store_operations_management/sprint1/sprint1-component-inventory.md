# Sprint 1 Component Inventory

Vanilla ES Modulesの既存方針を維持し、フレームワークは追加していない。

| Component | Responsibility |
|---|---|
| StickyFilters | 対象月、Scope、月次/累計、最終更新 |
| ExecutiveSummary | 結論、主指標3件、状態件数、反映状況 |
| PriorityActionCard | テーマ、店舗、理由、期待効果、関連タブ導線 |
| BusinessDriverGroup | KPI主従表示、モバイルアコーディオン |
| StoreStatusFilters | 5区分と件数 |
| StoreTable | PC比較、行全体遷移 |
| StoreCard | 1023px以下の比較表示 |
| StoreDetailTabs | 4タブと矢印キー操作 |
| SalesComposition | 店舗売上/EC按分の階層と構成バー |
| DataStateText | 状態アイコン＋日本語表示 |
| MockControls | 開発用Role/Runtime/利益/未反映切替 |

追加UI単位: 11。既存Runtime、Adapter、共有Design Systemを再利用。
