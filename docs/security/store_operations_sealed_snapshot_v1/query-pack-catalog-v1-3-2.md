# Fixed Query Pack Catalog v1.3.2

QP04 `SOCE-QP04-EMPLOYEE-AUTHORIZATION-SUMMARY` uses the Canonical
Organization Assignment Foundation. It reports the exact effective Sales
department-head candidate count and, only in the sealed private artifact, the
Canonical employee key and employee number required for run authorization.

No Auth schema relation, Auth subject, legacy role label, or position label is
used to establish the Operator.
