# Repair Flow

## 固定フロー

```text
Work Queueを開く
  → 現在値と修正候補を確認
  → 修正値を入力または重複候補を選択
  → 保存して次へ
  → 次の1件を表示
```

## 操作ステップ数

- 学校名・氏名・状態不足: 3ステップ（確認、入力/選択、保存）
- 重複候補: 3ステップ（比較、採用候補選択、保存）
- 保留: 2ステップ（判断不能確認、保留して次へ）

## 保存契約候補

正式実装では、1回の保存につきCandidate 1件または重複候補1組だけを更新する。監査履歴、Owner、変更前後カテゴリ、時刻を保存し、競合時はfail closedとする。

今回のbranchではDB/Production書込みを実装しない。
