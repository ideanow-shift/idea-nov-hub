# 現在案の強み

## 維持する設計

- Runtime／Projectionを唯一のデータ入口とし、UIに業務ロジックを持たない
- Roleにより代表・営業部長・AMはDashboard、店長は自店舗詳細へ着地する
- Executive Summary、優先事項、業績要因、店舗一覧、詳細という大枠がある
- 優先アクションを最大3件に制限している
- 店舗状態を好調、安定、改善中、要対応の4区分で扱う
- 店舗詳細が4区分で、冒頭に結論と今月の重点を置く
- 未取得値を0にせず、データ状態を表示する
- PC一覧の比較性能と、モバイルカード表示を両立する
- 行全体遷移、44px操作領域、focus、ARIA、矢印キーTab移動を考慮する
- 一覧へ戻った際の条件とスクロール位置を保持する

## 画面品質として強い点

余白と罫線で大きな情報群を分け、数字ごとのカード化を避けている。状態が文字でも示され、モバイルではテーブルをカードへ変換している。これらはIDEA NOV ERP全体へ展開できる基礎である。

## 維持条件

強みを残すには、追加要求を新カードとして足さず、主従または展開領域へ割り当てる必要がある。特に、比較情報を主KPIと同格にしないこと、準備中項目が取得済み項目を押し下げないことが条件となる。
