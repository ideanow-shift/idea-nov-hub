# 店舗ポートフォリオ表示仕様

## 役割

店舗状態の分布を理解し、そのまま店舗一覧を絞り込む。独立した大きな分析カードやグラフにはしない。

## 表示

Executive Summaryでは「好調 3｜安定 10｜改善中 5｜要対応 2」のようにコンパクトに示す。業績ドライバーと一覧の間では、同じ4状態と「すべて」を薄いSelectorとして表示する。

各状態は色だけでなく、状態名、件数、選択形状を持つ。健康スコア、順位、固定点数、判定式は表示しない。

## 操作

- 初期選択: 要対応
- 状態選択: 店舗一覧を即時絞り込み
- 0件: 0件の状態を保持し、勝手に「すべて」へ変えない
- 空状態: 「該当する店舗はありません」＋「全店舗を見る」
- Scope変更: 全店／直営／FCの範囲で件数を再計算

## 重複防止

店舗名、個別KPI、改善テーマをこの領域へ並べない。それらは店舗一覧へ委ねる。Portfolioの役割は「分布」と「Filter」に限定する。
