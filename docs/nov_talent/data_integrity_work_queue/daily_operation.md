# Daily Operation

## 毎日の手順

1. Data Integrity Work Queueを開く。
2. 今日の修正件数と残件数を確認する。
3. 上から1件ずつ修正する。
4. 判断できない重複は保留する。
5. 修正済件数と残件数を終業前に確認する。

## 処理能力の想定

- 不足項目: 1件1～2分
- 重複候補: 1組3～5分
- 1人30分: 8～15件
- 1人60分: 15～30件

初日は17件を対象とし、30～60分で一次処理完了を想定する。ただし重複判断に原票確認が必要な場合は保留を許容する。

## 終了条件

- 本日の残件数0、または未判断案件がすべて保留理由付き
- 保存失敗や競合がない
- 個人値をチャット・通常ログへ出していない
