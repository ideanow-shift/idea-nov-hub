# 既存画面の認知上の強み

## 確認範囲

今回の添付フォルダには画像ファイルがなく、本文だけが提供されていた。代わりに、リポジトリ内のPhase 5基準画像（PC、タブレット、スマートフォン、一覧、詳細、データ状態）とレビュー記録を確認した。本資料は、画像から観察した事実と、指示文に記載された現場評価を混同しない。

## 画像から確認できた強み

| 観察 | 認知上の効果 | V1へ残す原則 |
| --- | --- | --- |
| 大見出しと主要数値のサイズ差が大きい | 最初に見る場所を迷いにくい | 結論、主KPI、補足の3階層を維持 |
| 対象月、確定状態、更新日時がまとまっている | 数値の「いつ」を確認しやすい | 期間・鮮度・利益状態を同じ文脈に置く |
| 指標が罫線で整列している | カード乱立を避けつつ比較できる | 独立判断単位だけカード化する |
| 店舗詳細で「今月やること」が数値より先 | 数値を見る目的が先に分かる | 結論→確認事項→KPIの順を採用 |
| 状態を文字付きで表示 | 色覚に依存せず意味が分かる | 色＋状態名＋形／アイコンを併用 |
| PC一覧は店舗ごとの数値軸が揃う | 行間比較が速い | 数値右揃え、店舗と状態は左揃え |
| モバイル一覧をカード化した改善版がある | 横スクロールなしで店舗状態を読める | PC表の縮小ではなく要点カードに変換 |

## 指示文に記載された現場評価

現場評価として「月次進捗が見やすい」「日次進捗が把握しやすい」「現在地が分かりやすい」「予算との差が理解しやすい」「状況判断がしやすい」が提示された。ただし、元の添付画像は確認できないため、その具体的な視覚要因は断定しない。

V1へ移すのは、日次表示そのものではなく次の認知原則だけである。

- 対象期間と比較基準を数値の近くに置く
- 現在値と予算差を同じ読み単位にする
- 良し悪しの結論を先に示し、内訳を後から開く
- 同じ軸で店舗を揃え、視線を縦に動かして比較できるようにする
- 次の確認先を具体的な動詞で示す

## 持ち込まないもの

日別推移、日次進捗、リアルタイム監視、スタッフ個人分析、個人ランキング、単純売上／利益ランキングは持ち込まない。画像確認後も、このV1境界を越える機能は追加候補にしない。

## 再レビュー事項

元の添付画像が提供された場合、視線開始点、予算差の符号・形状、進捗表現、情報密度、一覧固定要素を再観察する。機能の移植ではなく、認知原則の妥当性だけを再評価する。
