# 利用者別要件

## 店長

MVP必須: 当月売上、予算差、前年差、客数、技術/店販、スタッフ別実績、生産性、コメント、更新日時/締め状態。

後続: 今日の売上、指名、新規/リピート、具体的な次アクション。

権限は自店舗のみ。配属の有効日を適用し、別店舗更新をdenyする。

## エリアマネージャー

MVP必須: 担当複数店舗比較、エリア合計、遅れている店舗、店舗別推移、店長コメント参照。

後続: 改善対象の自動抽出、指示workflow。

現状は構造化area assignmentが不足し、role名だけではscopeを確定できない。

## 営業部

MVP必須: 全店舗進捗、店舗ランキング、予算達成率、異常値フラグ、店舗コメント、CSV/PDF用の会議データ。

後続: 原因分析、改善指示workflow、高度な資料自動生成。

全店舗scopeをroleだけで付与せず、法人・直営/FC境界を明示する。

## 経営者

MVP必須: 全社、法人別、直営/FC別、店舗別月次売上、予算比、前年比、分離された生産性KPI。

後続: 店舗別収益性、予測。

店舗売上と会計P/Lは更新頻度・意味が異なるため、同一数値として混在させずreconciliation statusを表示する。

## 共通表示契約

すべての画面にperiod、as-of、source、close status、last imported、correction status、unit、tax basisを表示する。データ欠損は0に変換せずUnknown/Pendingとする。
