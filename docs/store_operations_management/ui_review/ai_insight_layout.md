# AI洞察配置

## 方針

大きなAIコメント領域を作らない。Executive Summary、優先アクション、店舗詳細の結論、現在の課題へ短く統合する。AIというラベルより、根拠と次の確認を優先する。

## 良い文章の型

「観測事実」＋「優先順位」＋「次に確認すること」。

例: 「新規客数は前年並みですが、新規リピート率が6.8pt低下しています。集客より、次回予約プロセスを先に確認してください。」

## 悪い文章

- 数値を文章化しただけ
- Sourceにない原因を断定
- どの店舗にも当てはまる一般論
- 長い免責やAI説明
- 行動を命令し、人の判断余地を奪う表現

## 信頼形成

洞察の近くに対象月、対象Scope、関連KPI、現在値、比較差、データ状態を置く。ユーザーが一操作で根拠へ移れるようにする。取得できないデータから洞察を作らず、生成できない場合は通常の状態説明へ戻す。

## 無視されるリスク

同じ文が毎日変わらない、根拠が追えない、行動が抽象的、間違いを訂正できない場合に無視される。V1では文章の派手さより、具体的な「次に確認」を評価する。
