# Sprint 1 Internal Review Guide

## 準備

1. リポジトリ直下で `.\start-preview.bat` を実行する。
2. Chromeで `http://127.0.0.1:4174/portal/store-sales/` を開く。
3. 「プレビュー」「画面確認用のサンプルデータ」「実績値ではありません」の表示を確認する。
4. 確認用コントロールのRuntimeを`ready`にする。

## 代表または副社長

1. Roleを「代表取締役」にする。
2. 全20店舗の全店状況、要対応数、優先事項を確認する。
3. 10秒以内に全体状況と要対応数を把握できるか評価する。

## 営業部長

1. Roleを「営業部長」にする。
2. 全店の状況、要対応店舗、優先して確認することを確認する。
3. 店舗一覧を状態で絞り込み、売上・利益・リピート率・生産性で並び替える。
4. 店舗行を開いて詳細へ移動する。
5. 一覧へ戻り、フィルター、並び順、スクロール位置が保持されるか確認する。

## エリアマネージャー

1. Roleを「エリアマネージャー」にする。
2. 担当5店舗だけが表示されることを確認する。
3. 要対応店舗を特定し、店舗詳細へ移動する。

## 店長

1. Roleを「店長」にする。
2. 自店舗詳細が初期表示されることを確認する。
3. 今月の重点、その他の確認事項2件、次に確認することを読む。
4. サマリー、売上・利益、顧客・リピート、価値・生産性の4タブを確認する。

## スマートフォン

1. Chrome DevToolsまたは実端末でスマートフォン幅にする。
2. 店舗一覧がカード表示になり、ページの横スクロールがないことを確認する。
3. カードをタップして店舗詳細へ移動する。
4. KPIの「結果」が開き、他グループをタップで開閉できることを確認する。
