# 1on1 MTG

- 目的/利用者: 面談記録とfeedback。社員・manager。
- 判定: **Unknown / 20% / 本番未確認**
- URL/repo/技術/認証/DB/table/owner: 未確認。
- Core/HUB: employees/manager relationship候補。HUB static cardのみ確認。
- 完成/未完成/不具合: 実装を確認できず、全項目未確認。
- セキュリティ: 要配慮個人情報、閲覧scope、保持/削除。
- 推奨: 実体確認まで新規再構築を開始しない。
- 根拠: `portal/apps.json`, `portal/js/apps.js`
- 最終確認: repo、URL、運用者、既存面談データ。
