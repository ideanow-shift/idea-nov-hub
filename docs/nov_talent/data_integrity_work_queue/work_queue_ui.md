# Work Queue UI

## 表示するもの

- 今日修正するデータ
- 指定されたKPI 4項目
- 今日の修正カテゴリ
- 現在値
- 修正候補
- 修正入力
- 保存して次へ
- 保留して次へ
- 今日残っている対象

## 表示しないもの

- 分析、グラフ、ROI
- イベント分析、学校分析
- CSV取込画面
- Migration操作画面
- 採用Dashboard
- 候補者全件一覧
- 開発者用の内部ID・raw error・接続情報

## 操作

- 通常不足: 修正値を入力して `保存して次へ`
- 状態不足: 状態を選択して `保存して次へ`
- 重複候補: 候補Aまたは候補Bを正として選択。判断不能は `保留して次へ`
- 1操作で2件以上を更新しない

## モバイル

現在の修正カードを最初に表示し、残Queueはその下へ配置する。横長テーブルを使わず、ボタンは48px以上とする。
