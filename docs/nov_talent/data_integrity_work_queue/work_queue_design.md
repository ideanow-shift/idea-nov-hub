# Work Queue Design

## 目的

総務人事部が毎日、今日修正する対象だけを上から処理する。分析、CSV、Migration、学校分析、イベント分析は表示しない。

## 画面構造

1. 今日修正する件数
2. KPI 4項目: 整合率、修正済件数、残件数、Migration進捗
3. 不足・重複カテゴリ件数
4. 現在修正する1件
5. 今日残っている対象

## 今日のQueue

- 学校名不足: 1件
- 氏名不足: 4件
- 状態不足: 2件
- 重複候補: 10組
- 担当者不足: 正本列未確定のため未集計
- 次回対応不足: 正本列未確定のため未集計

本日の確定対象は17件。未集計項目を0件と偽表示しない。

## 境界
