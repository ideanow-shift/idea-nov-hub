# 弥生会計Excel構造監査

## 1. 結論

対象Excelは、単一法人の年間推移残高試算表を、38集計単位についてB/S・P/Lの対で出力した76シート構成である。全P/Lは同一レイアウト、B/Sも全社合計だけ末尾行が1行少ない以外は同一レイアウトであり、見出し・科目名・年月を使うparserで継続取込できる見込みがある。

判定は **Conditional Go**。店舗・部門候補別P/L、月次値、累計値、主要利益は機械取得できる。一方、次の3点は経理確認前に本番利用できない。

1. 全シートが税抜出力であり、店舗営業管理の税込売上表示と一致しない。
2. P/Lの6月列と7月列が全38シートで同値、8月列が全件ゼロである。ファイル名「6月まで」と列見出しだけでは7月を実績と判断できない。
3. シート名は会計部門名であり、Core上の店舗・法人・部門IDと未確定である。

会計金額、口座別補助科目、原本ファイルはGitへ保存していない。

Excelのused rangeは書式のためA:IVまで伸びるが、実データはA:Rに限られる。セル位置だけでなく、A1/A3/A5/A6/A8と月見出しの組合せでデータ領域を確定する。

B/Sは月次増減額ではなく各月末残高である。全38 B/Sシートで上半期列は2月残高、下半期列は8月残高と一致したため、月次SUMは禁止する。

## 5. 科目と小計

### P/L

- 直接識別可能: 技術売上高、商品売上高、ECサイト商品売上高、売上高合計、材料仕入、商品仕入、売上原価、売上総損益金額、販売管理費計、営業損益金額、経常損益金額、税引前当期純損益金額、当期純損益金額。
- 販管費明細: 給与手当、賞与手当、法定福利費、福利厚生費、減価償却費、賃借料、水道光熱費、広告宣伝費、支払手数料など。
- 人件費という単一行はないため、構成科目を定義して算出する。
- `期首商品棚卸高`と`期末商品棚卸高`は同名行が各2行あり、account codeもstyle差もない。見出しcontextと標準行だけでは将来変化時に誤結合し得るため、経理の科目意味確認が必要。

### B/S

- 現金預金、売掛金、棚卸資産、流動資産、固定資産、資産合計、買掛金、短期借入金、長期借入金、流動負債、固定負債、負債合計、純資産、負債・純資産合計を直接識別できる。
- 補助科目の専用列はない。現金預金配下に口座別とみられる行が並ぶが、通常科目・補助科目・小計を区別するcode、indent、style差は確認できない。
- 機密保護のため、口座別ラベルは成果物の科目mappingへ転記しない。Phase 3ではprivate mappingとして管理する。

## 6. 数値・空欄・ゼロ・文字列

- 数値セルはB:R、ラベルは主にA列である。
- 数式セルは0件で、数値セルはExcel保存実値である。
- 科目見出し行は数値欄が空欄、金額未発生の科目は数値の0を持つ。空欄と0を同一視してはならない。
- 正負両方の数値がある。parserは表示文字列ではなくnumeric valueとsignを保持する。
- 結合セルは0件。定義名も0件。
- 文字列を数値としてparseする必要はないが、将来CSV対応時はカンマ、括弧負数、空欄を別規則にする。

## 9. PDF突合

リポジトリおよび確認可能な保存先に、指定された2026年1〜6月の店舗別月次損益PDFは確認できなかった。2025年の店舗月次損益PDF候補は期間外のため使用していない。

したがって、売上高、売上総利益、営業利益、経常利益、主要経費、月次、累計のPDF突合は **未検証**。Phase 3のgolden reconciliationで、代表3店舗×2か月以上を照合する。
