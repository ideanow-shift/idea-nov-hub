# Sprint 1 UI Review Reflection

反映項目は18件。

1. サマリーを単一の大きな面に統合
2. 主情報を売上・利益状態・要対応数の3件に限定
3. 店舗状態4区分の件数を併記
4. 未反映店舗数を文章で明示
5. フィルターだけをsticky化
6. 優先カードをテーマ起点に再構成
7. 優先カードを最大3件に制限
8. 関連タブへの直接遷移
9. KPIを4グループ化
10. 主KPIと補足KPIの文字階層を分離
11. 店舗状態フィルターに件数表示
12. 行全体をクリック/キーボード操作可能に変更
13. モバイルをカード表示に変更
14. 詳細冒頭を結論文に変更
15. 売上内訳を階層＋構成バーで表示
16. 利益状態と店舗状態の視覚表現を分離
17. 店長向け重点・確認事項・次導線を追加
18. 44px操作領域、フォーカス、ARIAを整備
