## 5分以内に判断できるか

| Role | 判定 | 条件 |
| --- | --- | --- |
| 代表取締役 | 条件付きで可能 | Summary結論と優先3件が最上位にあること |
| 副社長 | 条件付きで可能 | Scopeと横断要因が明確であること |
| 営業部長 | 条件付きで可能 | 全アクティブ店舗と利益Data ScopeをServerが解決し、担当者・優先テーマを一覧まで追えること |
| エリアマネージャー | 可能 | 担当Scopeだけで優先順位が出ること |
| 店長 | 可能 | 自店舗結論、今月の重点、次に確認を数値より先に置くこと |

現状のままではExecutive Roleの結論文と根拠説明が弱いため、無条件のGOではない。

## 最大リスクへの回答

- 使われなくなる最大理由: 月次情報が更新されず、優先アクションも変わらないため、開いても新しい判断が得られないこと
- Spreadsheetへ戻る最大理由: 店舗間の比較列、Filter、sort、内訳が不足すること
- 感情的抵抗を減らす方法: 状態を評価ではなく「確認優先度」と説明し、理由と支援行動を併記する
- 優先アクションの信頼形成: 根拠KPI、差分、対象期間、データ状態、詳細導線を同じ判断単位にする
- 店舗状態の納得感: Black box scoreを見せず、状態理由と関連KPIを追跡可能にする
- 利益確定前の価値: 売上、顧客、単価、継続・運営の確定済み指標と今月の重点を提供し、利益は集計中と予定日を正直に示す
- 誤認防止: 全店売上と直営店利益には別々の対象店舗数を表示し、同一母集団に見せない

## 継続利用の条件

営業部と店長が使い続けるには、画面を開いた結果が会話の開始点になる必要がある。「見る」だけでなく、「誰に何を確認するか」を5分で言えるかをUXレビューの合否基準にする。
