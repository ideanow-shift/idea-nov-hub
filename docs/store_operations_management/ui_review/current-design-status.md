# 現行設計の完成度

## 判定

情報設計、Permission境界、V1対象範囲、PC／Tablet／Mobileの基本構造は確定済みである。本Sprintでは、実装者に残っていた寸法、部品状態、操作、状態保持、Design Tokenの判断を確定した。以後のUI実装で新たな画面構成判断は不要である。

## 既存画面資産

| 領域 | 維持する強み | 本Sprintで固定した事項 |
| --- | --- | --- |
| Dashboard | 状態→優先→要因→店舗の順 | 密度、初期表示範囲、6経営シグナル、共通推移 |
| 店舗一覧 | 状態と改善テーマ中心 | 最終列、列優先度、行高、Responsive |
| 店舗詳細 | 結論と今月重点を先行 | 4 tab、上部要約、内訳、グラフ、戻る |
| Role別表示 | Server許可集合を正本 | 初期画面、表示／非表示、403 |
| 状態表示 | 業務状態と通信Failureを分離 | 全状態の文言、範囲、操作 |

## 非UIの未接続事項

正式API、Production Session、実データProjectionの接続可否はUI設計完成判定に含めない。UIは値を推測せず、Contractが返す状態を本仕様の表示へ写像する。未接続時にSyntheticへfallbackしない。
