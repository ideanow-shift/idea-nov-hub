# Work Queue UI

## 表示するもの

- 今日修正するデータ
- 指定されたKPI 4項目
- 今日の修正カテゴリ
- 現在値
- 修正候補
- 修正入力
- 修正内容を確認
- Spreadsheet修正済
- 次へ
- 今日残っている対象

## 表示しないもの

- 分析、グラフ、ROI
- イベント分析、学校分析
- CSV取込画面
- Migration操作画面
- 採用Dashboard
- 候補者全件一覧
- 保存ボタン、DB反映、Production反映
- 開発者用の内部ID・raw error・接続情報

## 操作

- 重複候補: `同一人物`、`別人`、`判断保留`のいずれかを確認
- 正本Spreadsheetを修正した後に `Spreadsheet修正済`
- `次へ` で初めて次の1件を表示
- Work Queueはいかなるデータも保存・更新しない

## モバイル

現在の修正カードを最初に表示し、残Queueはその下へ配置する。横長テーブルを使わず、ボタンは48px以上とする。
