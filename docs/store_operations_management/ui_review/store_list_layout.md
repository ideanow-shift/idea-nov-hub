# 店舗一覧表示仕様

## 認可境界

一覧はServerが返した許可済み店舗ID集合だけを表示する。全店／直営／FCはPermission Scopeではなく、その集合を狭める表示Filterである。frontend claim、Filter、URLで集合を拡張しない。scope外店舗は一覧に出さず、直接URLは403「対象店舗の閲覧権限なし」とする。

利益閲覧Data Scopeがない利用者には利益列自体を表示しない。FC店舗行の利益は「V1対象外」とし、集計中や0円にしない。

全店FilterのSummaryでは「直営店利益（対象○店舗）」と売上対象店舗数を分ける。件数は許可済みかつ有効な直営店舗から算出する。詳細は[利益状態表示仕様](profit_status_layout.md)を正本とする。

列順は店舗名＋状態、改善テーマ、担当AM、総売上、利益／状態、予算比、前年比、総客数、総単価、総リピート率、総生産性。初期sortは状態優先度（要対応→改善中→安定→好調）、同順位は売上前年比昇順、店舗名昇順。すべての数値列は昇順／降順、文字列列は昇順／降順を選べる。

1366pxでは総客数・総単価・総生産性を隠し、列表示menuから追加できる。1440pxでは全列を基本表示するが、収まらなければ同じ3列をこの順で隠す。1920pxは全列。店舗、状態、改善テーマ、担当AM、売上、利益状態、前年比はユーザー操作で非表示にできない。利益Data Scopeなしは列menuにも利益を出さない。

## 行と画面幅

header高44px、行高56px。行全体をクリック／Enter可能にし、店舗詳細へ遷移する。1024px未満はカードへ切り替え、Tabletは店舗、状態、改善テーマ、担当AM、売上、許可された利益状態、主要比較を優先する。Mobileは1列カードとし、横スクロール表を使わない。カードの表示順は店舗＋状態、改善テーマ、担当AM、売上、利益状態、最重要差分、詳細導線とする。

## 状態保持

対象月、月次／累計、全店／直営／FC、店舗状態Filter、並び順、列表示、スクロール位置、許可済み店舗集合のversionを遷移文脈として保持する。「一覧へ戻る」で表示状態を復元するが、Session／Scope更新後はServerの最新許可集合を優先する。

## 空・Failure

0件でもFilterを維持し「全店舗を見る」を示す。ただし「全店舗」は許可済み集合の全件である。Store Scope未解決は403、API未接続は503、Projection未生成は503、通信失敗は再試行として区別する。
