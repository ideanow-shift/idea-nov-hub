# Sprint 3.1 Demo Dataset

## 目的

営業部が導入後の利用場面を想像できるよう、実績値を使わずに現実感のあるSynthetic Dataを表示する。

## データ条件

- 対象: 正式20店舗（直営13、FC7）
- 対象月: 2026年6月
- 総売上（税込）: 2.778億円
- 営業利益: 2,364万円
- 利益状態: 全店舗を「Synthetic確定値」に統一
- 店舗状態: 好調3、安定10、改善中5、要対応2
- 売上: 1,040万〜1,860万円の範囲で順位差を設定
- 営業利益率: 2.8%〜12.4%の範囲で店舗状態と自然に対応

すべて画面確認用に作成した架空値であり、実売上、実利益、実KPI、実会計データではない。

## 要対応店舗のデモテーマ

- ANNEX店: 新規リピート率の改善。期待効果は既存客数の増加。
- 久米川店: 客単価と再来店率の改善。期待効果は売上と利益の安定。

## 設計方針

好調・安定を中心にしながら、朝の確認で対応対象を2店舗まで絞れる分布とした。売上順位、利益率、リピート率、店舗状態が完全な単調関係にならないよう調整し、比較と会話が生まれるデモにしている。
