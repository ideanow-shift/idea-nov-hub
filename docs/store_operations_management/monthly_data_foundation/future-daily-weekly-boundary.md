# Future Daily And Weekly Boundary

This foundation is monthly-only. Daily and weekly analysis is V2 scope, after the
POS provider's bulk-export capability is complete. V2 is designed around one file
per store, not the V1 all-20-store monthly file.

A future sprint must independently approve source systems, cadence, cut-off time,
correction policy, identifier mapping, role visibility, aggregation rules, and
release readiness. A daily or weekly file must not be relabeled as a monthly file to
bypass these gates.
