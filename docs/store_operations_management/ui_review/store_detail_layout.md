# 店舗詳細表示仕様

## 目的

「この店舗で何が起きているか」「なぜか」「最初に何を確認するか」を5分以内に判断する。Dashboardの縮小版にしない。

## 共通上部

1. 一覧へ戻る
2. 店舗名、店舗状態、対象月、利益状態
3. 1〜2文の結論
4. 今月の最優先課題
5. 次に確認すること
6. 主要KPI要約

優先アクションから遷移した場合、関連区分を選択し、対象KPIを見出しで示す。自動スクロールだけに依存せず文脈を残す。

## 4区分

### サマリー

総売上、利益／状態、総客数、総単価、総リピート率、総生産性、現在の課題。すべてを同じサイズにせず、現在の課題に関係するKPIを主表示する。

### 売上・利益

総売上→店舗売上（技術、通常店販、MID）＋EC按分→利益の順。構成は横型積み上げbarを使い、二重計上でない階層をlabelでも示す。利益は確定状態を伴う。

### 顧客・リピート

総客数を主に、新規／既存を内訳とする。総リピート率を主に、新規／再来／固定を展開する。月別推移は当年／前年比較。

### 価値・生産性

総単価、総生産性を主に、技術単価、店販売上、店販購買率を補助とする。「稼働スタッフ数 14.2人相当」と補足をタップでも開ける。

## 状態と遷移

準備中項目の領域は維持するが、無効な詳細導線を置かない。戻ると一覧状態を復元する。店長初期表示では他店舗への導線や全店Filterを表示しない。
