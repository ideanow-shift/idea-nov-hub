# Business Decision Items

最大15件に限定した。以下は技術実装で決めず、CEOまたは営業部責任者を含むownerが承認する。

| ID | 判断事項 | Owner | 決定内容 |
|---|---|---|---|
| BD-01 | 店舗売上の正式正本 | CEO + 営業部責任者 + CTO | POS/Salon系/公式CSV/Spreadsheetのどれを正本にするか |
| BD-02 | 売上の税基準 | CEO + 経理責任者 | 標準表示・計算を税込または税抜のどちらにするか |
| BD-03 | 総売上・純売上の構成 | 営業部責任者 + 経理 | 値引、取消、返品、返金、MID、ECをどこに含めるか |
| BD-04 | 技術・店販・指名category | 営業部責任者 | source category、セット按分、複数担当を承認 |
| BD-05 | 生産性の正式分母 | CEO + 営業部責任者 | 稼働人数、FTE、確定労働時間を別KPIとしてどう採用するか |
| BD-06 | スタッフ数の定義 | 営業部責任者 + 人事 | 在籍人数、稼働人数、FTEのどれを各画面で使うか |
| BD-07 | 月中異動・応援の帰属 | 営業部責任者 + 人事 | 売上、人時、人員を実績日・主所属・勤務先のどこへ帰属させるか |
| BD-08 | MID売上の扱い | 営業部責任者 | 正式意味、商品売上との重複、除外指標を承認 |
| BD-09 | 顧客・新規・リピート定義 | 営業部責任者 | 顧客ID、全社/店舗初回、lookback、cohort期間を承認 |
| BD-10 | 店販購買率・指名率の分母 | 営業部責任者 | 総客数、技術客数、対象売上の組合せを承認 |
| BD-11 | 予算の正式version | CEO + 営業部責任者 | 当初/修正/承認予算と遡及改定規則を承認 |
| BD-12 | 営業日と締め | 営業部責任者 + 経理 | 境界時刻、月次close、再open、遡及修正を承認 |
| BD-13 | 稼働率の意味 | CEO + 営業部責任者 | 人員、実労働時間、予約枠のどれを測るか |
| BD-14 | 直営/FCの法人関係 | CEO + 営業部責任者 | 所有・運営・集計法人と閲覧scopeを承認 |
| BD-15 | ランキング規則 | CEO + 営業部責任者 | 採用KPI、欠損、速報、同順位、eligible populationを承認 |

## 技術的に固定できる事項

- IDは名称ではなくCore IDを使う。
- technical keyはsnake_case、term_idはcategory.keyとする。
- 0除算はNULL、丸めは表示時、訂正は新versionとする。
- source fileはchecksum、batch、row、mapping、auditで追跡する。
- unresolved/ambiguous mappingはquarantineし、集計へ混入させない。
