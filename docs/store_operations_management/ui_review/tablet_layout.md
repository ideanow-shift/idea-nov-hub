# タブレット設計

## 利用文脈

店舗巡回、立った状態での確認、店長との会話を想定する。PCより情報を絞るが、スマートフォンほど単一列へ寄せない。

## 配置

- Executive Summary: 全幅
- 優先アクション: 1〜2列、最優先を左上
- 業績ドライバー: 2列×2段
- Portfolio: 全幅の状態Selector
- 店舗一覧: 主要列tableまたは2列カード
- 店舗詳細: 主KPI 2列、詳細群2列

## 操作

hoverに依存しない。補足はtap／focusで開き、閉じる操作を持つ。44px以上、行全体遷移、sticky headerを基本にする。横持ちでもPCの全列を無理に表示しない。

## 比較

店舗、状態、改善テーマ、売上、利益状態、予算比／前年比を優先し、客数、単価、リピート、生産性は行展開で確認する。巡回中に「次にどこを見るか」が変わらない順序を維持する。
