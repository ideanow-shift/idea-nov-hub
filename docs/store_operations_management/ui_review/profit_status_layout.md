# 利益・Failure状態表示仕様

## 利益閲覧の正式UI契約

| 状態 | 意味 | UI |
| --- | --- | --- |
| 確定済み | 経理確定済みでData Scope内 | 確定利益、利益率、対象月、必要時「確定」 |
| 集計中 | 月次損益が未確定 | 「集計中」、確定予定時期 |
| 準備中 | データ連携または機能が未準備 | 「準備中」、必要時に準備内容 |
| V1対象外 | FC店舗利益などV1で扱わない | 「V1対象外」、構造上自然なら項目非表示 |
| 閲覧権限なし | Data ScopeまたはStore Scope外 | 原則KPI項目自体を非表示 |
| API未接続／Projection未生成 | 接続または生成が未完了 | 「接続準備中」／「利用不可」。503として扱う |
| Preview | Mock Projection | 「Preview」「実績値ではありません」「Mock値」 |

集計中を0円、準備中を`—`、権限なしを準備中、FC利益を集計中、API未接続を利益集計中、Preview値を実績値として表示しない。

## 全店表示時の利益範囲

全店売上と利益の母集団は同じとは限らない。FC利益はV1対象外のため、全店Filterでは「全店利益」と表示せず、次を使う。

- 全店Filter: `直営店利益（対象○店舗）`＋`FC店舗利益はV1対象外`
- 直営Filter: `直営店利益`
- FC Filter: `利益 V1対象外`
- AMの直営・FC混在Scope: `担当直営店利益（対象○店舗）`

対象店舗数は13固定ではなく、表示時点の許可済み店舗ID集合に含まれる有効な直営店舗数から算出する。売上対象店舗数と利益対象店舗数をそれぞれ明記する。

## 視覚分離

利益の集計中／準備中はneutralな状態icon＋文字で示す。店舗状態の「改善中」と同じbadge、色、形を使わない。読み込み中はsystem loadingであり、集計中と別領域にする。閲覧権限なしは内部Role、Permission Key、Store IDを表示しない。

## Failure UX

| 状態 | 分類 | UI |
| --- | --- | --- |
| 未ログイン | 401 | 再ログイン |
| セッション期限切れ | 401 | ログイン有効期限切れ |
| employee／role／Permission未解決 | 403 | 利用権限なし |
| Store Scope未解決 | 403 | 利用可能な店舗がありません |
| scope外店舗URL | 403 | 対象店舗の閲覧権限なし |
| API未接続 | 503 | 接続準備中 |
| Projection未生成 | 503 | データ準備中 |
| 利益未確定 | 200 | 集計中 |
| FC利益 | 200 | V1対象外 |
| Preview | 200 | Preview・実績値ではない |
| 通信失敗 | system error | 読み込みに失敗・再試行 |

すべてを「アクセス権限がありません」へ統合せず、raw error、schema、内部Role、正式Key名は利用者へ表示しない。
