# 優先アクション表示仕様

## 役割

30秒以内に今日最初に見る店舗を決める。最大3件で、カードの主語は店舗名ではなく改善テーマとする。

## カード内の順序

1. 改善テーマ
2. 店舗名＋店舗状態
3. 対象KPIの現在値
4. 予算差または前年同月差
5. 影響度
6. 次に確認すること
7. 具体的な遷移ラベル

例:

> 新規リピート率を改善
>
> 立川店　要対応
>
> 現在値 31.2%　前年同月差 −6.8pt　影響度 高
>
> 次に確認: 新規カウンセリングと次回予約提案率
>
> ［原因を確認］

## 相互作用

カードまたは「原因を確認」を選ぶと、店舗詳細の関連区分へ移動し、対象KPIを見失わないよう見出しで示す。抽象的な「詳細を見る」は使わない。

## 順位の説明

UIは判定式を持たない。Server Projectionが返す順を表示し、ユーザーには影響度、状態、差分、継続傾向という根拠を短く見せる。同一店舗の複数テーマは原則1カードへまとめ、全3件が同じ店舗になる状況を避ける。

## 空・状態

- 0件: 「現在、優先して確認する店舗はありません。」＋「全店舗を見る」
- KPI集計中: 数値を出さず状態と、取得できる確認事項だけを示す
- 詳細データ準備中: 無効な導線を置かず、確認可能時期を示す
- エラー: カードを部分生成せず、領域単位で再試行を示す
