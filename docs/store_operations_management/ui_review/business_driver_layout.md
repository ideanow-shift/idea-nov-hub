# 業績ドライバー表示仕様

## 役割

優先店舗を選んだ後に「何が原因か」を60秒以内に確認する。4グループを維持し、全KPIを同じ強さで並べない。

| グループ | 主KPI | 補助・内訳 |
| --- | --- | --- |
| 結果 | 総売上（税抜）、利益／利益状態 | 予算比、前年同月比、年間累計 |
| 顧客 | 総客数 | 新規客数、既存客数 |
| 価値 | 総単価 | 技術単価、店販売上 |
| 継続・運営 | 総リピート率、総生産性 | 店販購買率 |

総リピート率を複数グループへ重複表示しない。新規／再来／固定リピート率は店舗詳細または展開後に置く。

## PC／Tablet／Mobile

- PC: 4列。1366pxでは2列×2段も許容する
- Tablet: 2列×2段
- Mobile: Accordion。初期は「結果」を展開し、優先アクション関連群も自動的に開く

## グラフ

Dashboardでは共通の月別推移を1つだけ使う。質問は「変化は一時的か継続的か」。折れ線で当年と前年を比較し、初期系列は優先テーマに対応する主KPI、展開後に予算を追加する。モバイルは直近6か月の簡略線＋月／値の表を代替とする。

KPIごとの装飾用mini chart、円グラフ、ランキング、日別推移は使わない。

## 状態

準備中の補助KPIは位置を保ちつつ、主KPIより目立たせない。グループ全体が準備中なら、個別行を大量に並べず理由と対象項目を一つにまとめる。
